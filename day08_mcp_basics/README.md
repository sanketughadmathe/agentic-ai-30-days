# Day 8 – MCP Basics

Focus:
- Understanding MCP as a boundary, not a feature
- Exposing tools via an MCP server
- Consuming tools safely from an agent

Key Concepts:
- Tools live outside the agent
- MCP defines what is allowed, not the prompt
- Agents request actions, servers execute them

Why this matters:
Without MCP, tool execution is implicit and unsafe.
With MCP, tool access becomes auditable and controlled.

This is the foundation for secure agent systems.
