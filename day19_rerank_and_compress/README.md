# Day 19 – Context Compression & Reranking

Focus:
- Retrieve more candidates
- Rerank using LLM scoring
- Select top relevant documents
- Reduce context before generation

Key Concepts:
- Retrieval optimizes recall
- Reranking optimizes precision
- Too much context hurts model focus
- Compression improves generation quality

Why this matters:
RAG quality depends not just on finding documents,
but on selecting the best ones.
