# Day 14 – Observability Basics

Focus:
- Introduce trace_id for each agent run
- Structured logging
- Visibility into node execution

Key Concepts:
- Every run should be traceable
- Logs must include a correlation id
- Observability comes before optimization

Why this matters:
Without traces and logs, agent failures
become anecdotes instead of debuggable events.

This lays the groundwork for LangSmith
or OpenTelemetry later.
