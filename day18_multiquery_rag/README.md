# Day 18 – Multi-Query Retrieval

Focus:
- Query rewriting using LLMs
- Improving recall with multiple search queries
- Deduplicating retrieval results

Key Concepts:
- Retrieval failures often come from weak queries
- One query rarely captures full semantic intent
- Multiple rewritten queries increase coverage

Why this matters:
Multi-query retrieval significantly improves
RAG performance without increasing context window size.
